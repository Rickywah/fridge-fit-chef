# 细化食材营养库与菜谱动态重算

**日期：** 2026-07-25  
**状态：** 已实施  
**范围：** 内置食材 per-100g 营养、菜谱/临时餐克重折算、整餐份量调节（0.5× / 1× / 1.5×）  
**不做：** TDEE / 减脂增肌目标、自动蛋白替换、微量营养素、在线营养 API  
**主文件：** [`web/fridge-fit-chef.html`](../../../web/fridge-fit-chef.html)

---

## 问题

1. **大类均值误差大：** `CAT_NUTRITION` 对禽肉/红肉等统一 P/C/F（如禽肉 P24/F5 per 100g）。鸡胸、鸡腿、瘦牛、肥牛无法区分。
2. **菜谱营养写死：** `calcRecipeNutrition` 优先返回 `recipe.nutrition`，不按食材克重重算；减量/加量无法联动宏量。
3. **临时组合餐只有区间：** `estimateMealNutritionRange` 基于大类均值再加 margin，无法给出可信单值。
4. **自定义通道已存在但内置未用：** 自定义食材有 `p100/c100/f100`；`FOOD_DB` 项没有独立营养。

---

## 已确认决策

| 项 | 选择 |
|----|------|
| 优先子项目 | A · 细化营养库（TDEE、替换匹配拆后续） |
| 数据来源 | 内置精编（中国食物成分表口径），离线 |
| 生熟策略 | 库存默认按**生重**；少量熟食独立条目（如熟鸡胸肉、熟米饭） |
| 营养字段 | 每 100g：`protein` / `carb` / `fat` / `kcal` |
| 菜谱行为 | 按食材克重动态求和；UI 提供整餐 **0.5× / 1× / 1.5×** |
| 数据结构 | 直接扩展现有 `FOOD_DB`（`id` + `nutrition100` + `state` + `source`） |

## 食材模型

```javascript
{
  id: 'chicken-breast-raw',
  name: '鸡胸肉',          // 对用户：默认生重
  state: 'raw',            // raw | cooked | n/a
  unit: '块',
  grams: 200,
  cat: '禽肉',
  nutrition100: {
    protein: 23.1,
    carb: 0,
    fat: 1.9,
    kcal: 110
  },
  source: '中国食物成分表'
}
```

### 命名与细分

- 保留现有名称语义：`鸡胸肉`、`去皮鸡腿肉` 等 = **生重**，避免破坏已有 `localStorage` 库存。
- 新增常用细分（首版至少）：
  - 带皮鸡腿肉
  - 瘦牛肉、肥牛片（现有模糊「牛肉」保留并映射为生瘦牛肉数据，新添加优先展示细分名）
  - 五花肉
  - 熟鸡胸肉
- `NAME_ALIASES` 继续解析旧名/俗名到正式 profile。

### 查找优先级

1. 内置 `nutrition100`（经 `resolveName` / `id`）
2. 自定义食材 `p100/c100/f100`（缺 kcal 时用 4/4/9 推算）
3. `CAT_NUTRITION` 大类兜底，结果标记 **「含估算项」**

`CAT_NUTRITION` 不再作为正常路径的主数据源。

## 计算

### 单品

```
grams = quantity × gramsPerUnit
factor = grams / 100
P/C/F/kcal = nutrition100.* × factor
```

### 菜谱 / 临时餐

- 对每样食材求和，得到整餐宏量。
- **忽略**写死的 `recipe.nutrition`（保留字段仅作迁移回退，正常路径不读）。
- 全部食材有精确 profile → 展示单值。
- 任一食材走大类兜底 → 展示单值 + 「含估算项」（不再对完整库默认给宽区间）。

### 份量调节

- 状态：`servingScale ∈ { 0.5, 1, 1.5 }`，默认 `1`。
- 缩放对象：
  - 食材用量展示
  - 宏量 / kcal 展示
  - 「做完扣库存」扣减量
- 推荐引擎仍按 `1×` 做可行性匹配；用户在结果页改份量后即时重算，不强制重跑推荐。
- `1.5×` 导致库存不足时：允许查看营养，明确提示缺料；**不扣库存**。
- `0.5×` 允许小数单位扣减（如 0.5 块）。

## 非目标

## 验收标准

1. 同克重鸡胸肉与带皮鸡腿肉的脂肪/热量明显不同。
2. 瘦牛肉与肥牛片营养结果不同。
3. 1× 菜谱宏量由食材求和得出，不直接返回旧写死 `nutrition`。
4. 切换 0.5× / 1.5× 后，用量、宏量、热量、扣库存同比变化。
5. 库存不够 1.5× 时提示缺料且不扣库存。
6. 旧库存名称与自定义食材仍可用。
7. 全精确数据不默认显示宽区间；有兜底时出现「含估算项」。
8. `tests/smoke.ps1` 通过。
